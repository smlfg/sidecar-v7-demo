Sektion 1

Dein unsichtbarer Co-Pilot

Sidecar laeuft als Daemon im Hintergrund. Bei jedem Prompt, bei jedem Tool-Call schaut es mit — ohne dass du etwas tun musst.

Was es ist

Ein Python-Daemon der ueber einen Unix Socket mit Claude Code kommuniziert. Hooks in ~/.claude/hooks/ senden Events, Sidecar antwortet mit Context-Injection, Coaching-Nudges oder Safety-Blocks.

Zwei Geschwindigkeiten

<5ms Fast Path — deterministische Regeln, Cooldowns, Pattern-Matching. Kostet $0.

~2-5s Slow Path — MiniMax M2.5 Deep Analysis mit Function Calling. ~$0.0003/Call.

Fail-Open Design

Wenn Sidecar abstuerzt oder der Socket nicht erreichbar ist, laeuft Claude ganz normal weiter. Die Bridge hat ein 3-Sekunden-Timeout und liefert statischen Fallback-Kontext.

💬 Context Injection — Sidecar fluestert Claude Kontext zu

Bei jedem einzelnen Prompt injiziert Sidecar zusaetzlichen Kontext in das additionalContext-Feld. Claude sieht ihn, du nicht.

  • Phase-Erkennung — Wo bist du gerade? exploration implementation testing debugging
  • Workflow-Phase — Abgeleitet aus der Activity-Phase: planning → build → test → deploy
  • Contract-Tracking — Pflichten pro Phase (must/should). Score 0-100%. Warnung wenn Obligations nicht erfuellt.
  • Anti-Pattern-Warnungen — Erkennt Hypothesen-lose Delegation, Silent Long-Running, Vibe-Coding ohne Verstaendnis.
  • Skill-Empfehlungen — 14 Skills, phasenbasiert. In Exploration: /research, in Testing: /test.
  • ADHS-Patterns — Hyperfocus-Warnung, Session-Sprawl-Erkennung, Paralysis-Detection nach 20min.
  • Personal Context — Energie-Level (Peak 13-17h), Stimmung (Keyword-Analyse), Tageszeit, Angst-Themen.
  • Twin Memory — Relevante Beobachtungen aus der Memory-DB (Insights, Fear-Log, gelernte Konzepte).
Hook: UserPromptSubmit → bridge.py → daemon.py → ContextBridge.enrich() → additionalContext

🎯 Coaching-Nudges — 48 situative Impulse

48 Mechanismen in 8 Kategorien. Nur eine Nudge pro Prompt (first-match nach Prioritaet).

  • Prioritaets-System — ADHS (Tier 0) > Fokus/Qualitaet (1) > Projekt (2) > Lernen (3) > Dopamin/Awareness (4)
  • Cooldown-System — Jeder Mechanismus hat einen eigenen Cooldown (60s bis 3600s). Verhindert Spam.
  • EWMA-Ratings — Gewichtete Bewertung (alpha=0.3). Top-Performer feuern oefter, Underperformer seltener.
  • MechanismResult — Jede Nudge kann: Text anzeigen, Claude's Prompt anreichern (enrich_prompt), und Twin-Queries ausloesen.
  • Du-Perspektive — 47/48 Mechanismen sprechen dich direkt an. Nur safety_gate (#29) blockiert sofort ohne Anrede.
  • 8 Kategorien — Fokus (7), Lernen (6), Projekt (5), Dopamin (5), Awareness (5), Qualitaet (4), ADHS (4+4), Workflow (6+1+1)
Registry: mechanisms.py → coach.py wire_all() → fire_all() (priority-sorted)

🗣 Florian spricht — Hoerbares Coaching

Edge TTS mit de-DE-FlorianMultilingualNeural. Sidecar spricht Nudges laut aus — du hoerst Coaching, ohne auf den Bildschirm schauen zu muessen.

  • TTS-Server — Systemd Service auf Port :5050. Health-Check bei Start, Auto-Restart wenn down.
  • Was gesprochen wird — Fokus/ADHS-Nudges (sofort), Slow-Path-Ergebnisse (zusammengefasst), Commit-Digests, Feierabend-Summary.
  • Cooldowns pro Typ — celebration: 30s, milestone/commit: 60s, info: 120s, narration: 120s, commit_digest: 240s, goal/scope_creep: 300s, coaching: 300s, paralysis: 600s, feierabend: 1800s
  • Dedup — Ring-Buffer der letzten 10 gesprochenen Texte. Keine Wiederholungen.
  • STT-Antworten — Whisper STT. Samuel kann auf gesprochene Nudges antworten (max 3 Runden Dialog).
  • TTS Voting — Multi-dimensional: Content (1-3), Timing (1-3), Form (1-3) + dismiss_ms. Legacy-kompatibel mit +1/-1.
  • Text-Aufbereitung — Backticks entfernt, Pfade gekuerzt, Abkuerzungen expandiert (PR→Pull Request, LOC→Lines of Code), Zahlen 0-12 als Woerter.
samuel/florian.py → Edge TTS :5050 → paplay/pw-play/aplay | samuel/stt.py (Whisper)

🛑 Safety Gates — Blockiert gefaehrliche Aktionen

PreToolUse Hook. Geprueft bevor ein Tool ausgefuehrt wird. Blockiert sofort — kein Cooldown, keine Bewertung.

Gefaehrliche Bash-Befehle
  • rm -rf ~/ oder rm -rf . — Loeschen von Home/Root/CWD
  • git push --force — Force Push
  • git reset --hard — Hard Reset
  • DROP TABLE / DROP DATABASE — SQL Drop
  • chmod 777 — Unsichere Berechtigungen
  • mkfs.* — Dateisystem formatieren
  • sudo / su — Kein TTY in Claude Code
  • > /dev/sd* — Direktes Schreiben auf Block Devices
Secret Exposure (Warnung)

Bei Write/Edit: Warnt wenn API Keys, Passwörter oder Tokens im Code erscheinen. ANTHROPIC_API_KEY, MINIMAX_API_KEY, OPENAI_API_KEY, AWS_SECRET_ACCESS_KEY, password=, token=.

WebSearch/WebFetch in SubAgents

Blockiert WebSearch und WebFetch komplett — erzeugen Permission-Prompts die Samuel unterbrechen. Stattdessen: Gemini MCP als Background-Agent.

Prueft auch Agent-Prompts auf "websearch"/"webfetch" Keywords und blockiert diese.

Hook: PreToolUse → safety.py check_safety() + check_secret_exposure() → block/allow

🧠 Deep Analysis — MiniMax Slow Path

Periodische LLM-Bewertung deiner Arbeit durch MiniMax M2.5 mit sandboxed Function Calling.

  • 4 Tools — read_file, list_dir, search_code, write_protocol (sandboxed, read-only + Protokoll)
  • Adaptives Intervall — 10min (clean), 5min (1+ Fehler), 3min (3+ Fehler)
  • Event-Trigger — Error-Burst, Phase-Change, Stuck-Detection loesen sofortige Analyse aus
  • Budget — $0.50/Tag, ~$0.0003/Analyse. BudgetTracker verhindert Ueberschreitung.
  • Ergebnis-Pipeline — Analyse-Ergebnis wird auf den naechsten Prompt geprepended + optional von Florian vorgelesen.
  • Coaching Rules — MiniMax kennt Samuels Regeln aus coaching_rules.txt: Research First, Delegation, CLI First, Intent First, Session-Hygiene.
samuel/harness.py → MiniMax M2.5 Agent Loop → Function Calling → write_protocol → next prompt

Sektion 5

Sidecar lernt mit dir

Das System tuned sich selbst. Gute Nudges feuern oefter, schlechte seltener, tote werden deaktiviert.

EWMA Ratings

Jeder Mechanismus hat eine gewichtete Bewertung. alpha=0.3 — 30% neues Signal, 70% Historie.

Startwert: 3.0 (neutral). Erster Wert wird direkt uebernommen, danach gewichtet.

Auto-Rating Signale

  • +0.5 Commit nach Nudge
  • -0.5 Fehler-Burst nach Nudge
  • +1/-1 Manuelles TTS-Voting
  • Multi-dim Content + Timing + Form + Dismiss-Speed

AdaptationEngine (alle 30min)

Weighted Score = 0.4 × success_rate + 0.3 × trend + 0.3 × context_match

  • Score > 0.8 Cooldown halbiert — "Top Performer"
  • 0.3 – 0.8 Keine Aenderung — "Normal"
  • Score < 0.3 Cooldown verdoppelt — "Underperformer"
  • Score < 0.15 Deaktiviert — "Remove"
  • 48h ohne Fire Dormant auto-disable

Spaced Repetition

Ebbinghaus-Intervalle fuer gelernte Konzepte: 1d → 3d → 7d → 14d → 30d

  • Gap Detection — Gleicher Fehler 3+ mal = Knowledge Gap
  • Max 2 Reviews/Session — Nicht ueberfluten
  • Persist — JSON unter /tmp/sidecar-v7-learner.json
